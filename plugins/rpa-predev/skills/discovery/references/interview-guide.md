# 과제 발굴 인터뷰 가이드

## 발굴 질문 (현업 담당자용)

**반복 업무 찾기**
- 매일/매주/매월 같은 방식으로 반복하는 업무는 무엇인가요?
- 시스템 A에서 보고 시스템 B에 옮겨 적는 일이 있나요? (복사-붙여넣기 업무)
- 엑셀을 내려받아 가공한 뒤 다시 올리거나 메일로 보내는 일이 있나요?
- 월말·분기말에 몰려서 야근하게 만드는 업무는 무엇인가요?
- 신입에게 "이건 그냥 이 순서대로 하면 돼"라고 가르치는 업무는?

**규모 파악 (ROI 필수)**
- 한 번에 몇 건을 처리하나요? 한 달이면 대략 몇 건인가요?
- 1건 처리에 몇 분 걸리나요? (화면 이동·대기 포함)
- 몇 명이 이 업무를 하나요?

**자동화 적합성 신호**
- 처리 규칙을 글로 적을 수 있나요? 아니면 "보면 안다" 수준인가요?
- 입력 자료는 어떤 형태인가요? (엑셀 / PDF 양식 / 메일 본문 / 종이 스캔)
- 사용하는 시스템이 곧 바뀌거나 개편될 예정이 있나요?
- 자주 생기는 예외 상황은? 그때는 어떻게 처리하나요?
- 개인정보·금융정보가 포함되나요? 공동인증서/OTP 로그인이 필요한가요?

## 업무 단위 정하기

- **하나의 과제 = 하나의 트리거 → 하나의 결과물.** 트리거나 결과물이 다르면 별도 과제로 나눈다.
- 같은 시스템·같은 규칙으로 대상만 다른 업무(예: 거래처 A/B/C 정산)는 하나로 합친다.
- 업무명은 "대상 + 행위 + 시스템" 명사구로 통일한다 (예: "월말 거래처 정산 데이터 ERP 등록").

## 자동화 부적합 신호 (발굴 단계에서 표시만, 탈락시키지 않음)

| 신호 | 의미 | 대안 |
|------|------|------|
| 사람 판단 필수 | 규칙화 불가 | 판단 전후 구간만 부분 자동화 / RDA |
| 비정형 입력 | 양식이 매번 다름 | IDP(OCR+AI) 결합, 입력 양식 표준화 |
| 월 5시간 미만 | 효과 작음 | 유사 업무와 묶어서 재검토 |
| 시스템 개편 예정 | 개발 후 재작업 | 개편 이후로 연기 |
| 공동인증서·OTP | 기술·보안 제약 | 보안팀 협의 선행 |
