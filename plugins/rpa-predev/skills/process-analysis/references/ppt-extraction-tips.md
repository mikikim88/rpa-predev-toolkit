# PPT 입력 자료 분석 시 주의사항

현업이 작성한 PPT는 다음과 같은 특성을 가지므로, 텍스트와 이미지를 함께 봐야 정확한 분석이 가능합니다.

## 현업 PPT의 일반적 특성

### 1. 슬라이드에 캡션이 없거나 부족함
- 화면 캡처만 붙여놓고 "이 화면에서 처리"라고만 적은 경우 다수
- → **반드시 썸네일 이미지를 봐야 함**. 화면의 메뉴명, 버튼 위치, 입력 필드를 직접 읽어내야 합니다.

### 2. 슬라이드 순서가 작업 순서가 아닐 수 있음
- 설명 편의상 화면별로 묶어 놓은 경우 (예: 같은 시스템 화면을 여러 단계에 걸쳐 사용해도 한 곳에 모아 표시)
- → 작업 흐름을 재구성하면서 "Step N에서 다시 사용" 같은 표기 추가

### 3. 암묵적 절차가 많음
- 현업이 당연하게 여기는 "기본 동작"이 빠져 있음
- 예시:
  - "거래처 조회" → 사실은 "메뉴 진입 → 검색조건 입력 → 조회 버튼 → 결과 더블클릭" 4단계
  - "데이터 다운로드" → "조회 → 엑셀 변환 버튼 → 저장 위치 선택 → 파일명 입력" 4단계
- → Step을 봇이 인식 가능한 단위로 분해

### 4. 예외 처리 누락
- "정상 처리"만 설명하고 오류/예외 케이스가 거의 없음
- → 분석서의 "확인 필요" 슬라이드에 반드시 예외 항목 다수 포함됨이 정상

### 5. 데이터 명세 부족
- "엑셀 파일 첨부"라고만 적혀있고 컬럼 구조, 건수, 형식이 없음
- → 첨부 예시가 있다면 화면 캡처에서 추출, 없으면 "확인 필요" 표기

## 텍스트 추출 + 이미지 분석 병행 방법

### 텍스트 추출
```bash
python "<플러그인>/scripts/extract_pptx.py" <첨부파일>.pptx --images <작업폴더>/images
```
- 슬라이드별 텍스트 박스, 그룹 도형, 표, 노트의 모든 텍스트가 `## Slide N` 단위로 추출됨
- `--images`를 주면 슬라이드에 삽입된 스크린샷이 `slideNN_imgK.png`로 저장됨
- 이미지 안의 텍스트(스크린샷 속 메뉴·버튼명)는 추출되지 않음 → 이미지를 직접 확인

### 시각 분석
```bash
python "<플러그인>/scripts/preview_pptx.py" <첨부파일>.pptx -o <작업폴더>/preview
```
- 슬라이드 전체를 PNG로 렌더링 (Windows PowerPoint 또는 LibreOffice 필요)
- Read 도구로 이미지를 직접 확인하여 화면 내 정보(메뉴, 버튼, 필드명) 파악
- 렌더러가 없으면 `--images`로 추출한 개별 스크린샷을 확인

### 분석 시 활용 패턴
1. 먼저 extract_pptx.py로 전체 흐름 파악
2. 화면 캡처가 많은 슬라이드는 썸네일/개별 이미지로 시각 확인
3. 텍스트와 이미지 정보를 결합하여 Step 도출
4. 이미지에서 보이지만 텍스트에 없는 정보 = 자동화 구현 시 중요 단서

## 자주 놓치는 정보 체크리스트

분석 시 다음을 의도적으로 찾아봅니다:

- [ ] 시스템 정확한 명칭 (PPT 캡처 화면 상단 제목바에서)
- [ ] 메뉴 경로 전체 (좌측 메뉴 트리에서)
- [ ] URL 또는 화면 ID (브라우저 주소창, SAP 트랜잭션 코드 등)
- [ ] 입력 필드의 정확한 라벨명 (한글/영문 혼용 주의)
- [ ] 필수 입력 vs 선택 입력 표시 (별표, 빨간 테두리 등)
- [ ] 드롭다운 선택지 목록
- [ ] 버튼 라벨 (확인/저장/완료 등 유사어 구분)
- [ ] 알림 팝업 메시지 내용
- [ ] 처리 완료 표시 방법 (상태 변경, 메시지, 메일 발송 등)

## 입력 자료가 부실할 때 대응

PPT 자료가 매우 빈약한 경우 (예: 슬라이드 5장 이내, 화면 캡처 거의 없음):

1. 분석 가능한 부분만 우선 작성
2. "확인 필요" 슬라이드에 인터뷰 질문지 형태로 정리
3. 사용자에게 "현재 자료로는 N개 항목이 추가 확인 필요합니다. 분석서 v1.0을 먼저 작성하고, 인터뷰 후 v2.0으로 보완 권장"을 안내

## 입력 자료가 풍부할 때 (50장 이상)

대용량 PPT의 경우:
1. extract-text 결과를 슬라이드별로 빠르게 스캔
2. 핵심 슬라이드 그룹 식별 (시스템 소개 / 절차 / 예외 / 데이터)
3. 각 그룹에서 대표 슬라이드만 시각 확인
4. 동일 시스템 반복 캡처는 첫 1-2장만 확인하고 나머지는 텍스트로 처리
